# Casimirs FlappyBuddy

**How to setup**

Move into this folder.
With 'poetry install' you can setup your python environment.


## How to run a bot

'poetry run python -m bot UpAI'

## Benchmarking

For each run of a bot some metadata will be stored in a json file under the subfolders of 'data'
To visualize multiple metafiles of one directory you can run 'poetry run python -m visualize_benchmarks.py'
Inside this code you can also specify the folder containing the .json files, of the runs.
